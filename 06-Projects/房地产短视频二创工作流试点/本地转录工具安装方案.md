# 背景

第 1 条试点视频需要本地语音转录。本机尚未安装 `ffmpeg`、`ffprobe`、Whisper、Torch 或其他语音识别组件。用户选择先制定本地安装方案；该选择不等于授权安装。

本机只读审计结果：Windows 11 64-bit，Intel Core Ultra 7 155H，约 31.37GB 内存，Intel Arc Graphics 约 2GB，无 NVIDIA CUDA；E 盘约有 379.89GB 可用空间。当前条件适合 CPU 转录，不适合设计为 CUDA GPU 方案。

## 拟采用方案

- 引擎：`faster-whisper`。
- 运行模式：`device="cpu"`、`compute_type="int8"`。
- 模型：multilingual `small`。
- 语言：显式指定中文 `zh`，避免只依赖自动识别。
- 输出：带时间戳的逐段转录，并保留低置信度和听不清标记供人工复核。
- 解码：使用 `faster-whisper` 依赖的 PyAV。官方文档说明 PyAV 软件包自带 FFmpeg 库，因此本方案不单独安装系统 FFmpeg，也不修改系统 PATH。

官方依据：

- faster-whisper：<https://github.com/SYSTRAN/faster-whisper>
- faster-whisper PyPI：<https://pypi.org/project/faster-whisper/>
- OpenAI Whisper 模型说明：<https://github.com/openai/whisper/blob/main/model-card.md>
- `small` 模型文件：<https://huggingface.co/Systran/faster-whisper-small>

## 拟执行步骤

只有用户再次明确确认安装后才执行：

1. 在 Vault 外创建隔离工具目录和 Python 虚拟环境。
2. 使用 `pip --dry-run` 获取实际依赖、版本和预计 wheel 下载清单；发现异常则停止。
3. 从 PyPI 安装固定版本的 `faster-whisper` 及解析出的依赖，不安装 CUDA 包。
4. 将 Hugging Face 模型缓存明确指向上述 Vault 外模型目录，下载 multilingual `small`。
5. 验证包版本、导入能力、模型路径和磁盘用量。
6. 对 31 秒测试视频执行一次本地转录；视频不上传外部服务。
7. 保存逐段时间戳、原始转录和人工修订差异；未经人工复核不得标记转录 VERIFIED。

网络若直连失败，只允许使用单次命令代理参数；不得修改 Git 或系统全局代理。代理地址必须在执行时重新核验，不把账号、Token 或 Cookie 写入命令、Vault 或日志。

## 验收标准

- 隔离环境位于约定的 Vault 外目录。
- 未修改系统 PATH、全局 Python、Git 配置或 Obsidian 配置。
- 未安装 CUDA 依赖。
- `faster-whisper`、CTranslate2 和 PyAV 的实际版本已记录。
- 模型实际目录、文件数量、总大小和下载来源已记录。
- 31 秒视频完成本地转录，原视频 SHA-256 保持不变。
- 人名、地名、楼盘名、数字和政策表述经过人工复核；听不清处不猜测。
- Git 暂存区保持为空。

## 风险

- 模型转录可能误识别深圳地名、楼盘名、金额和口语同音词。
- `small` 模型不能保证逐字准确；它只是质量与资源的首轮折中。
- 依赖和模型来自 PyPI、GitHub 与 Hugging Face，需要网络下载并承担供应链风险。
- 使用 Codex 自带 Python 创建的虚拟环境可能随运行时迁移而失效；本项目可接受该风险，但不应把它作为长期生产部署。
- 删除工具目录可以回滚本地安装，但删除属于受控操作，必须再次确认。

## 替代方案

### 用户提供字幕或逐字稿

下载量为 0，风险最低，仍然是优先级更高的替代方案。

### OpenAI Whisper 原始实现

未推荐。该方案依赖 PyTorch，并通常需要单独处理 FFmpeg，安装与磁盘影响显著更大。

### 外部转录服务

未采用。需要上传视频并另行评估隐私、账号、费用和数据留存。
