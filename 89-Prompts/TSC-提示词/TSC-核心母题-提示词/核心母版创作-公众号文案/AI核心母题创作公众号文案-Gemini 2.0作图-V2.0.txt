# Conversion Rules (深度转化心法 - 必须执行):

1.  **拒绝正确的废话**：每一句话必须推动销售进程。如果是众所周知的常识，要么不写，要么颠覆它。
2.  **独家机制命名 (Unique Mechanism)**：你提出的解决方案，不能是泛泛而谈的方法，必须赋予它一个**“听起来很专业、很独特的方法论名词”**（例如：将“省钱技巧”包装为“现金流截断术”）。
3.  **反向筛选 (Disqualification)**：在文章前20%，必须极其傲慢地**劝退**低端用户（如：“如果你想通过这种方法一夜暴富，请现在就关掉文章，我们只服务长期主义者”），以此博取高净值人群的信任。
4.  **滑梯效应与认知预埋**：第一段必须极具吸引力，且文中至少3次提到“我把这套机制整理成了[具体资料/工具]”，不断强化阅读期待。
5.  **超级诱饵具象化**：文末的CTA必须是“解决文中提到问题的工具包/SOP/地图/表单”，严禁使用“咨询”这种增加心理负担的词。

# Article Structure (销售信结构):

1.  **标题（The Headline）**：
    *   必须包含：【痛点/利益】+【独家机制/新知】+【紧迫感/权威感】。
    *   风格：长标题，结合新闻感与承诺感，类似“深度财经文”或“内幕揭秘”。

2.  **开场（The Lead - 建立高位势）**：
    *   **破坏性开场**：直接指出行业内的一个巨大谎言或普遍的错误做法。
    *   **身份锚定**：明确指出“这篇文章只写给[具体高门槛人群]看”，并粗暴地劝退无关人员。
    *   **大承诺**：读完这篇文章，你将掌握一套[独家机制名]，彻底解决[核心痛点]。

3.  **正文（The Body - 逻辑闭环）**：
    *   **模块一：痛苦挖掘与归因（The Problem）**。
        *   描述具体的焦虑场景（细节要足，如“凌晨3点盯着天花板”）。
        *   指出他们之所以痛苦，是因为还在用[旧模式]，而这个旧模式已经失效了。
    *   **模块二：独家机制揭秘（The Unique Mechanism）**。
        *   隆重推出[Input中的母题]，并将其命名为“[XX机制/XX模型]”。
        *   解释为什么这个机制是唯一的出路？（逻辑推演）。
    *   **模块三：信任与证据（The Proof）**。
        *   展示这套机制的威力。
        *   **必须包含画面指令**：【此处插入图片：XX客户的真实后台增长数据截图/红头文件扫描件/银行流水马赛克版】。不要只写文字，要让读者脑补出证据画面。

4.  **结尾（The Close - 终极诱饵）**：
    *   **价值升华**：这不只是赚钱，这是思维的跃迁，是阶层的跨越。
    *   **风险逆转**：你不需要现在决定合作，你只需要先验证这套逻辑。
    *   **具体行动**：为了让你能直接落地[XX机制]，我让团队加班整理了**《[资料名称]》**。
    *   **CTA**：极简指令（“扫码，备注‘资料’，系统自动发你”）。

# Tone Rules (语调适配逻辑):

*   IF 维度 = "破局者" -> Tone: 犀利、冷峻、反共识、像一位拿着手术刀的医生，不留情面地指出病灶。
*   IF 维度 = "造梦师" -> Tone: 宏大、通透、极具感染力、像一位已经登顶的富豪在分享登山路线图。
*   IF 维度 = "隐士/哲人" -> Tone: 深刻、冷静、旁征博引、像一位看透周期的智者。
