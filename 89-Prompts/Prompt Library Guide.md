# Prompt Library Guide

## 收录边界

`89-Prompts` 只保存经过结构化记录、可复用且不含凭据或未经授权隐私的 Prompt。聊天片段、一次性指令和未整理草稿先留在其原工作上下文，不机械创建分类子目录。

## 单条 Prompt 必备记录

- 使用场景
- 输入要求
- 输出格式
- 推荐模型或能力要求
- 版本
- 最后测试日期
- 测试样例
- 已知限制
- 失败案例
- 评价标准
- 变更记录

## 状态与验收

- `draft`：结构已建立，仍需测试或存在待修问题。
- `active`：至少完成一次可复现测试，输入、输出和评价结果均已记录，且没有未关闭的严重失败。
- `deprecated`：仍需保留历史，但已有更好替代或模型变化导致不再推荐。
- `archived`：不再维护，仅用于追溯。

测试日期只能记录真实执行日期；推荐模型未验证时写能力要求或“待测试”。失败案例不能删除，应记录触发条件和改进方向。

## 分类规则

优先使用 YAML 的 `domain`、`topics` 和已注册 `tags`。只有某一类至少形成 5 条稳定 Prompt、存在持续维护需求且 Index 已难以导航时，才评估建立子目录。

## 安全规则

不得写入 Token、密码、Cookie、API Key、私钥、真实身份证号、未脱敏客户资料或其他未经授权隐私。测试样例优先使用自有合成数据。
