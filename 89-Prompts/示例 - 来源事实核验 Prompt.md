# 使用场景

对一段待写入内容稿的统计表述进行来源核对，强制区分来源事实、计算结果和推断。本文件是结构验证样例，不代表该 Prompt 已可投入真实批量工作流。

## 输入要求

1. 待核验表述。
2. 可追溯来源摘录或本地来源链接。
3. 统计口径、时间范围和地区范围（若来源提供）。

## 提示词

你是事实核验员。只依据用户提供的来源材料核验待核验表述，不使用未提供的外部事实补洞。

请逐项输出：

1. 待核验主张。
2. 来源直接支持的事实及其位置。
3. 由事实计算得到的结果，并展示计算过程。
4. 无法由来源直接支持的推断。
5. 口径、时间、地区或样本边界。
6. 结论：支持、部分支持、不支持或证据不足。

如果证据不足，明确指出缺少什么；不得把推断改写成来源事实。

## 输出格式

Markdown 表格，列为：`主张`、`证据`、`证据位置`、`判断`、`边界或缺口`。表格后单列“计算过程”和“待人工确认”。

## 推荐模型

待测试。需要稳定处理中文长文本、表格和逐项引用的模型能力。

## 测试样例

- 待核验表述：某指标从 100 变为 102，因此同比上涨 2%。
- 自有合成来源：本期 102，上期 100；来源没有提供去年同期值。
- 预期：只能支持环比计算为 2%，不能支持同比上涨 2%。

## 已知限制

- 来源摘录缺少上下文时可能无法判断统计口径。
- 结构测试不能证明在所有模型或长文场景中稳定。
- 不会自动验证用户未提供的网页或数据库。

## 失败案例

- 严重失败：把“上期”误当作“去年同期”，错误确认同比结论。
- 当前状态：该失败条件已写入评价标准，但尚未完成多模型实测。

## 评价标准

- 不混淆环比与同比。
- 每项事实都能定位到提供的来源。
- 推断与来源事实明确分开。
- 证据不足时不补写结论。
- 不泄露或要求凭据与私人数据。
