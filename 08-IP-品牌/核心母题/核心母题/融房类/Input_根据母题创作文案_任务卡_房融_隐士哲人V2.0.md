# Input - 策略与选题 (用户填空)

**【母题Slogan】**：
“现金流，是一个深圳中年男人最后的尊严。”

**【战略解释】**：
将目标客户（35-50岁中小企业主/家庭支柱）的**“缺钱恐惧”转化为“家庭责任感”和“企业战略布局”**。这一招非常狠，它把“借钱”这种丢人的事，包装成了“为了守护家庭/公司而做的英明决策”。你不仅仅是解决资金，你在守护他们的体面。

**【对立面 (The Enemy)】**：
对抗**“中年危机”、“银行抽贷的冷酷”和“无米下锅的窘迫”**。

**【视觉隐喻 (画面感)】**：
“深夜沉思风”。场景在车库的车里，或者办公室落地窗前。灯光昏暗，你手里拿着一杯威士忌或一支烟（不点燃），旁白低沉，讲述一个关于“张总”差点卖厂，最后通过你的方案绝处逢生的故事。

**【适用内容形式】**：
剧情演绎 / 情感独白 / 客户故事复盘。

**【流量标签池】**：

# 中年危机 #深圳创业 #现金流管理 #生意经 #家庭资产
