# 爆款设计清单

## 一、必过项

### 1. Hook 设计（3 个方案）

**方案 A：反常识断言（推荐）**
"深圳房价连续涨了三个月。但我劝你，别急着喊回暖。因为有一个数字，让我后背发凉。"
- 预期情绪：好奇 -> 紧张
- 适用场景：视频号口播开头

**方案 B：数据冲击**
"4 月涨 0.3%，5 月涨 0.4%，6 月涨 0.3%。深圳房价连涨三个月，看起来一片大好。但你再看同比——5 月突然从 -1.1% 崩到 -4.5%。发生了什么？"
- 预期情绪：震惊 -> 求知
- 适用场景：公众号开头 / 视频号备选

**方案 C：痛点共鸣**
"最近很多人问我：波哥，深圳房价涨了三个月了，是不是该上车了？我的回答是：你先看看这个数据再说。"
- 预期情绪：共鸣 -> 好奇
- 适用场景：视频号口播备选

### 2. 标题备选（3 个 + 画像）

| 标题                      | 目标画像            |
| ----------------------- | --------------- |
| 深圳房价连涨三个月，为什么我劝你别高兴太早   | 关注楼市但容易被情绪带动的人  |
| 环比全绿，同比全红：深圳房价的真实脸色     | 有一定数据分析习惯的理性购房者 |
| 5 月深圳房价发生了什么？一个数字让我后背发凉 | 喜欢悬念和故事性的普通观众   |

### 3. 情绪曲线

`
开头（Hook）：好奇/紧张 —— 涨了三个月为什么还泼冷水？
      |
中段（数据展开）：信心上升 —— 哦，确实在涨，4/5/6 月都在涨
      |
反转（5月同比）：震惊/焦虑 —— 等等，5 月怎么崩了？！
      |
解释（基期效应）：恍然大悟 —— 原来如此，环比涨同比跌是有原因的
      |
框架教学（四维度）：赋能感 —— 我学会了怎么看数据
      |
结论（冷静判断）：理性平静 —— 不急不躁，看数据说话
      |
收束（行动建议）：笃定 —— 有自己的判断框架了
`

## 二、可选项

### 4. 标签策略

- 泛流量（1 个）：#深圳房价 #楼市
- 垂直（2 个）：#深圳买房 #深圳房产
- 精准痛点（2-3 个）：#房价还会涨吗 #现在该不该买房 #买房避坑

### 5. 互动钩子

- 评论区引导："你买房前会看环比还是同比？评论区说说你的判断方法。"
- 争议点设计："有人说环比涨了就是回暖，你怎么看？"
- 转发诱因："转发给那个天天喊楼市崩盘的朋友，让他看看真实数据。"

### 6. 封面方向

- 核心视觉：深圳城市天际线背景 + 大号红色 vs 绿色数字对比
- 文字方向：主标题"涨了三个月，别高兴"，副标题"一个数字说明真相"

### 7. 信息密度节奏

| 时间段 | 信息点 | 情绪点 |
|--------|--------|--------|
| 0-5 秒 | Hook 反常识断言 | 好奇 |
| 5-15 秒 | 三个月环比数据展示 | 信心 |
| 15-25 秒 | 5 月同比突然恶化 | 震惊 |
| 25-40 秒 | 基期效应解释 | 恍然 |
| 40-55 秒 | 四维度框架教学 | 赋能 |
| 55-70 秒 | 回暖的三个条件 | 理性 |
| 70-80 秒 | 收束 + 行动建议 | 笃定 |
