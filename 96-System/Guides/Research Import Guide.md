# Research Import Guide

## 目的

把外部资料安全地进入 Vault，而不是把下载动作误当成知识沉淀。

## 导入前检查

- 确认资料来源合法，避免复制受版权保护的完整内容。
- 检查文件名和正文是否包含 Token、密码、Cookie、API Key、私钥或未授权隐私。
- 记录标题、来源、作者、发布日期和原始链接；未知值保持未知，不推测。
- 检查是否已有相同 URL、标题或文件哈希。

## 进入 Downloaded

`00-Inbox/Downloaded` 只在第一份真实资料导入时创建。

- 原始资料按原样保存，不在原文件上直接清理。
- 可下载文件保留原扩展名；网页转 Markdown 时同时保留原始 URL。
- 文件名先保证合法和可识别，不在导入阶段做批量重命名。
- 导入完成后记录文件大小、哈希和来源。

## 原始文件保护

Cleaner 必须写入新文件，推荐临时命名为 `<原文件名>--cleaned.md`。原始文件继续保留在 Downloaded，直到人工审查、确认可回滚，并依据明确保留策略处理。

## 禁止事项

- 不把摘要当作原文保存。
- 不因广告、导航或重复段落“看起来没用”就自动删除。
- 不覆盖原始文件。
- 不自动移动到 Research 或 Notes。
- 不为资料虚构作者、日期、来源或领域。
