# Content Production Workflow（正式 Guide）

> 最后更新：2026-08-13-v2
> 本文件由「知识库驱动视频选题与创作生产方案（第二轮）」合并扩写而来，是内容生产的唯一权威规则。

---

## 一、工作流总览

完整生产闭环：

```
竞品拆解 → 进料/挂载 → 选题候选 → 选题清单 → Brief → 爆款设计 → 创作 → 核验 → 发布 → 数据复盘 → 反哺
```

热点快速响应通道（独立子流程）：

```
触发事件 → Brief → 爆款设计 → 创作 → 核验 → 归档+轻量提取 → 发布 → 复盘
```

快速选题通道（独立子流程）：

```
Inbox素材 → Brief → 爆款设计 → 创作 → 核验 → 归档+轻量提取 → 发布 → 复盘
```

内容状态机：`idea → brief → draft → review → published → repurpose 或 archived`

视频或音频内容在制作正文时可以进入 `Scripts`；`Scripts` 是形式和存放职责，不是 YAML 状态。平台未正式登记，因此当前只使用平台无关母稿和通用模板，不创建公众号、抖音、小红书、知乎、视频号等平台目录。

---

## 二、各关卡退出条件

| 状态 | 必须具备 | 下一步 |
|---|---|---|
| `idea` | 一个清楚的问题、受众假设或内容机会，锚定到至少一条原子笔记或官方数据 | 补足角度与价值后进入 `brief`，否则归档 |
| `brief` | 双平台已标注（视频号+公众号）、受众、核心观点、证据来源、内容结构、核验点 | 通过爆款设计关卡后进入 `draft` |
| ★ 爆款设计 | 3 必过项完成（Hook 设计、标题备选、情绪曲线），4 可选项完成或标注缺失原因 | 通过后进入 `draft` |
| `draft` | 可审阅母稿或脚本（口播稿+公众号文稿各一份），证据链接可追溯，人设一致性检查通过 | 进入 `review` |
| `review` | 事实、表达、版权、隐私、广告合规、平台适配、爆款设计还原度检查 | 通过后进入 `published`，未通过返回 `draft` |
| `published` | 真实发布日期与发布链接 | 收集表现数据，进入复盘，决定 `repurpose` 或 `archived` |
| `repurpose` | 明确复用对象、变化范围和新受众 | 生成新的关联 Brief，不复制成失控母稿 |
| `archived` | 记录停止原因和保留价值 | 只读保留 |

## 三、单一母稿原则

- 一个 Brief 产出两个平台稿（视频号口播稿 + 公众号文稿），各自保留一份母稿，不按平台复制多份。
- 产出位置：
  - `05-Content/Scripts/<题> - 视频号口播稿.md`
  - `05-Content/Scripts/<题> - 公众号文稿.md`
- Research、Source 和 Atomic Note 只作为证据链接，不复制进内容稿。
- "房产视频文案"使用 `domain: "房地产"`，内容形式写"短视频脚本"或"口播稿"；它不是新的主领域。
- 平台未确定时写"待补充"，不猜测平台，也不建立平台目录。

---

## 四、竞品拆解（常态化进料，每周 1 条）

> 启动条件：第一批 3 条闭环跑通后启动。

- 输入：同赛道（深圳房产）近 7 天播放量最高的视频（不限账号）。
- 拆解维度：
  - Hook 类型（反常识断言 / 数据冲击 / 痛点共鸣 / 悬念提问 / 其他）
  - 情绪曲线（开头→中段→结尾的情绪变化）
  - 争议点设计（有没有故意制造认知冲突？什么冲突？）
  - 互动设计（评论区引导方式、CTA 策略）
  - 可复用模式（这条视频的"流量公式"是什么？）
- 产出：`05-Content/Ideas/竞品拆解-<日期>-<视频关键词>.md`
- 退出条件：五个拆解维度完整填写，且提取出至少 1 个可复用模式。
- 负责：AI 拆解 → 用户确认可复用模式。
- 资产：二创试点拆解方法论、黄金 5 秒开图、Hook 库。

## 五、选题候选与选题清单

### 选题候选生成

- 输入：07-Topics 枢纽 + 原子笔记 + 待核验清单里已放行的素材 + 竞品拆解库。
- 动作：从每条素材提炼 1 个或多个"可做选题"，标注：主题枢纽、切入角度、素材锚点、观点 vs 数据、置信度、时效性、建议形式（口播/图文/双稿）、可复用性。**起步阶段只筛选深圳相关选题。** 选题时参考竞品拆解库中的流量密码，标注"可借鉴的爆款模式"。
- 产出：`05-Content/Ideas/选题候选-<日期>.md`（一张候选表，按枢纽分组）。不建空目录、不预设空结构。
- 退出条件：每个候选必须锚定到至少一条原子笔记或官方数据；无依据的候选不保留；观点类候选显式标"待核验"。
- 负责：AI 生成候选初表 → 用户增删/圈选。
- 资产：89-Prompts 下的核心母题/选题/黄金 5 秒开图、Hook 库、竞品拆解库。

### 选题清单与排期

- 动作：按优先级（时效性、深圳优先、可复用性、证据成熟度、爆款潜力）排序，形成 backlog；定本周期做 3–5 条。
- 产出：`05-Content/Ideas/选题清单.md`（维护中的 backlog 索引）。
- 退出条件：明确每条候选的优先级与是否本周期做；被否的候选记原因（或归档），不静默丢弃。
- 负责：用户拍板选题；AI 提供排序建议。

## 六、爆款设计关卡（强制）

> 在 Brief 通过后、进入创作前，必须通过此关卡。不通过不进入创作。

- 输入：已通过审核的 Brief + 竞品拆解库 + Hook 库 + 黄金 5 秒开图。

### 必过项（3 项，缺一不可）

| 检查项 | 要求 | 产出 |
|--------|------|------|
| Hook 设计 | 用黄金 5 秒开图生成至少 3 个开头方案，标注预期情绪效果（好奇/震惊/共鸣/愤怒/焦虑） | 3 个 Hook 方案 |
| 标题备选 | 至少 3 个标题方案，标注各自吸引的用户画像 | 3 个标题 + 画像 |
| 情绪曲线 | 画出内容各段的预期情绪变化（痛点→共鸣→认知颠覆→解决方案→行动号召） | 情绪曲线图/描述 |

### 可选项（4 项，尽量完成，缺了标注原因）

| 检查项 | 要求 |
|--------|------|
| 标签策略 | 按热门话题漏斗公式组合（1 泛流量 + 2 垂直 + 2-3 精准痛点），风控注意用安全热词 |
| 互动钩子 | 评论区引导话术、争议点设计、转发诱因 |
| 封面方向 | 封面核心视觉元素和文字方向（不要求成品图，只要求方向描述） |
| 信息密度节奏 | 每 15 秒段落的信息点/情绪点密度检查，避免中段信息塌方 |

- 产出：`05-Content/Ideas/<题> - 爆款设计.md`
- 退出条件：3 必过项全部完成，4 可选项完成或标注缺失原因。
- 负责：AI 生成爆款设计清单 → 用户审核通过 → 放行进入创作。

---

## 七、创作与发布前核验

### 创作

- 输入：通过审核的 Brief + 通过审核的爆款设计清单。
- 动作：从同一 Brief 分别生成两个平台稿：
  - **视频号口播稿**：用 89-Prompts（波哥人设 + 口播稿提示词），口语化、时长可控。严格遵循爆款设计清单中的 Hook 方案、情绪曲线和标题方向。
  - **公众号文稿**：用 89-Prompts（公众号文案提示词），书面表达、带段落结构。标题和开头遵循爆款设计清单。
- 产出：
  - `05-Content/Scripts/<题> - 视频号口播稿.md`
  - `05-Content/Scripts/<题> - 公众号文稿.md`
- 负责：AI 生成初稿 + 清单 → 用户人工验收（程序/AI 不得自行宣布验收通过）。

### 发布前核验清单（全覆盖）

- [ ] 事实核验：数据口径（环比/同比/城市层级）、来源可追溯、日期明确
- [ ] 版权核验：不复制参考视频完整文案、独特表达、个人经历或创作者人格
- [ ] 广告合规：不使用"最佳时机 / 全面回暖 / 稳赚"等绝对化表达；引用数据带口径
- [ ] 公众号额外风控：不洗稿、不直接复制源文章段落；转载/引用标注来源；不使用违规诱导点击标题
- [ ] ★ 人设一致性检查（强制）：每一段是否通过了"波哥人设测试"？
  - 能不能让卖菜阿姨听懂？
  - 有没有用生活中的比喻（身体/汽车/恋爱/天气）？
  - 有没有毒舌味？
  - 有没有"降维翻译"——把专业术语翻成大白话？
- [ ] ★ 爆款设计还原度：实际成稿是否还原了爆款设计清单中的 Hook 方案、情绪曲线和标题方向？
- [ ] 口播实测时长不超过目标时长；如超时，优先删减修辞，不删除事实边界
- [ ] 发布前完成一次逐句人工核验

## 八、发布与表现数据

未发布时不得填写虚构日期、链接或表现数据。发布后记录可验证数据的来源与采集日期；没有采集时写"未采集"。

- 负责：用户提供发布事实与数据；AI 记录。
- 产出：Brief/Script 内更新状态与数据字段。
- 退出条件：状态更新为 published，数据项有来源与采集日期。

## 九、数据复盘

> 启动条件：第一批 3 条闭环跑通后，启用完整指标维度。第一批 3 条期间，有多少数据记多少，用于建立基线。

### 爆款复盘指标维度（预设，数据不齐时写"未采集"）

| 指标 | 用途 | 爆款参考线 |
|------|------|-----------|
| 5 秒完播率 | Hook 是否有效 | > 70% |
| 整体完播率 | 内容是否有信息密度 | > 30% |
| 互动率（评论+点赞+收藏）/ 播放 | 是否有争议/共鸣/实用价值 | > 5% |
| 转发率 | 是否有社交货币 | > 2% |
| 评论区高频词 | 观众真正关心什么 | 提取 Top 5 关键词 |
| 与同类选题横向对比 | 是选题问题还是执行问题 | 与竞品拆解库对照 |

### 复盘产出

每批内容一份复盘笔记（可挂到 05-Content 或相关 Topic），包含：
- 实际表现 vs 爆款设计预期
- 观察（数据事实）
- 推断（可能原因）
- 下一轮实验（改进假设）

复盘结论要区分观察、推断和下一轮实验。

### 复盘反哺机制

- "哪类 Hook 效果好/差" → 写回竞品拆解库和 Hook 库
- "哪类选题数据好/差" → 写回选题候选优先级排序逻辑
- "哪个情绪曲线模式表现好" → 写回爆款设计清单模板

## 十、热点快速响应通道（独立子流程）

> 启动条件：第一批 3 条闭环跑通后启用。

### 触发条件（写死，防止滥用）

以下任一事件发生时，可启动热点快速响应：
- 深圳出台房地产相关政策（限购/限贷/税费/公积金/人才房等）
- 国家统计局发布月度 70 城房价数据
- 深圳土拍出现重大结果（流拍/高溢价/新地王）
- 深圳新房开盘去化率显著异常（日光或去化率 < 10%）

### 流程

常规流程：竞品拆解 → 进料 → 选题候选 → 选题清单 → Brief → 爆款设计 → 创作 → 核验 → 发布 → 复盘

热点快速通道：**触发事件 → Brief → 爆款设计 → 创作 → 核验 → 归档+轻量提取 → 发布 → 复盘**

快速选题通道：**Inbox素材 → Brief → 爆款设计 → 创作 → 核验 → 归档+轻量提取 → 发布 → 复盘**

- 跳过"选题候选"和"选题清单"——热点本身就是选题。
- 其他关卡不变（Brief、爆款设计、核验、复盘全部保留，质量不妥协）。
- 时效目标：事件发生后 24 小时内完成 Brief + 爆款设计，48 小时内完成创作 + 核验。
- 热点触发时，热点优先于常规周更。如果热点导致本周常规产出减少，在复盘时标注原因，不计入周更达标率考核。

---

## 十一、节拍与节奏

- **起步阶段**：先跑通 3 条完整闭环（含 1 条已发布样板作为基准对照），验证流程可行性，再进入常态。起步阶段只做第一批升级（爆款设计关卡 + 人设一致性检查），竞品拆解和热点响应暂不启动。
- **常态**：每周 3–5 条常规内容 + 每周 1 条竞品拆解。每条需经爆款设计关卡、事实核验与人工验收。宁少但每条过核验，不批量堆未验收内容。
- 每条从 Brief 到验收预计 2–4 轮交互（取决于核验与改稿次数）。

> 风险提示：每周 3–5 条 + 1 条竞品拆解，意味着每条常规内容平均只有 1–2 个工作日。如果事实核验、爆款设计、改稿、人工验收的轮次超出预期，实际产出可能低于目标。建议起步阶段观察实际耗时，再校准常态目标。

---

## 十二、质量与风控（底线，不可妥协）

- 官方数据优先；观点类内容显式标注来源与低置信度，进入文案前重新核验数据是否过期。
- 不虚填日期、链接、表现数据；未采集写"未采集"。
- 版权：参考/二创只学结构与机制，不复制参考视频完整文案、独特表达、个人经历或创作者人格。
- 广告合规：不使用"最佳时机 / 全面回暖 / 稳赚"等绝对化表达；引用数据带口径（环比/同比/城市层级）。
- 公众号稿额外风控：不洗稿、不直接复制源文章段落；转载/引用标注来源；不使用违规诱导点击标题。
- 爆款与合规的平衡：爆款设计可以制造认知冲突和情绪张力，但不能以牺牲事实准确性为代价。争议可以来自于"挑战常识"，但不能来自于"歪曲数据"。
- 发布前逐句人工核验。

---

## 十二点五、归档 + 轻量提取（硬门槛，不完成不关闭生产通道）

> 适用于所有模式（完整模式、快速通道、热点响应）。每轮 M3 创作完成后强制执行。

### 归档

- 将本轮使用的 Inbox 素材按 domain 归档：房地产 → `04-Research/房地产/原始资料/`，财商 → `04-Research/财商/原始资料/`，小孩教育 → `04-Research/小孩教育/原始资料/`
- 素材标注 `status: processed`，关联已产出稿件（Brief + Script）

### 轻量提取

- 从每个素材中提取 1-3 个可复用要素，产出轻量提取卡片
- 要素类型：框架、概念、方法论、比喻、数据锚点
- 不追求完整拆解，只提取"下次创作能直接复用的要素"
- 产出：按 domain 放对应域，`04-Research/<domain>/轻量提取/<日期> <批次>-轻量提取.md`

### 退出条件

- 素材已从 Inbox 移动到 Research
- 轻量提取卡片已生成
- 累计轻量提取素材数 ≥ 5 时提示用户触发批量原子笔记提炼

---

## 十二点六、批量原子笔记提炼（独立触发）

> 触发条件：累计 5 个"已轻量提取"的素材后，AI 提示用户触发。用户确认后执行。不在生产通道内捆绑。

### 动作

- 读取 `04-Research/<各domain>/轻量提取/` 下所有未完整拆解的轻量提取卡片
- 对素材进行深度原子笔记提炼：概念定义、框架逻辑、数据来源核验、可复用方法论、比喻库
- 提炼后的原子笔记挂载到对应 Topic Hub（`07-Topics/`）
- 产出：`04-Research/<domain>/<对应子目录>/<原子笔记名>.md`（按内容类型归类：方法论/框架 → 房产咨询，市场数据/政策 → 市场行情，板块 → 板块分析，财商内容 → 财商域）
- 更新轻量提取卡片状态为 `status: atomized`

### 退出条件

- 所有待提炼素材完成原子笔记拆解
- 每条原子笔记挂载到至少一个 Topic Hub

---

## 十三、分工

- **AI**：生成选题候选、起草 Brief、生成爆款设计清单、生成初稿（口播 + 公众号）、整理核验清单与复盘、每周拆解 1 条竞品。但不代为验收、不宣布发布、不决定平台。
- **用户（波哥）**：拍板选题、审核爆款设计清单、人工验收每条文案（口播 + 公众号）、提供发布事实与表现数据、决定平台与节奏。

---

## 十四、范围边界（明确排除）

- 拍摄、剪辑、发布执行、账号运营与投流。
- 软件/界面/自动化开发（另立项目）。
- AI 技术本身的选题（仅作方法积累，不单独选题）。
- 全国大类城市选题（保留但暂不主动进选题；深圳起步）。
- 封面成品设计（方案只到封面方向描述，成品设计由用户或设计师完成）。

---

## 十五、里程碑

### 第一批（立即执行）

- M1：基于现有库内素材，生成第一批深圳选题候选清单。
- M2：用户圈选 3 题，完成 3 条内容 Brief + 3 份爆款设计清单。
