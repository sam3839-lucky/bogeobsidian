# Naming Convention

## 总则

- 文件名服务于人类检索；`id` 服务于稳定引用，两者职责不同。
- 正文与文件名可使用中文，YAML 字段名使用英文。
- 不在文件名前机械添加随机 ID。
- 不通过文件名编码所有分类；领域、主题和状态由 Properties 表达。

## Windows 合法性

文件名不得包含：`< > : " / \ | ? *` 或控制字符；不得以空格或句点结尾；不得使用 `CON`、`PRN`、`AUX`、`NUL`、`COM1`–`COM9`、`LPT1`–`LPT9` 等保留名。

## 通用格式

- 使用简洁、明确、可搜索的名词短语或结果短语。
- 中文与英文之间可保留一个空格；不使用连续空格。
- 避免 `最终版`、`最新版`、`新建文档`、`未命名`、`副本` 等失控词。
- 版本变化依靠 Git；确需文档版本时在正文或元数据说明。

## 各类型命名

| type | 文件名规则 | 示例 |
|---|---|---|
| `research` | `研究问题或对象` | `AI Agent 评测框架.md` |
| `source` | `来源标题 - 已知作者或机构`；作者未知则省略 | `世界发展报告 - 世界银行.md` |
| `atomic-note` | 单一概念或完整观点 | `检索增强不能替代来源核验.md` |
| `daily-note` | `YYYY-MM-DD.md` | `2026-08-09.md` |
| `project` | 可验证结果或交付物 | `建立房地产市场月度监测.md` |
| `decision` | `决策主题`；系统 ADR 可用 `ADR-NNN - 标题` | `是否采用统一内容母稿.md` |
| `prompt` | `任务 + 关键约束` | `研究报告事实核验提示词.md` |
| `content-brief` | `内容主题 - Brief` | `家庭 AI 素养 - Brief.md` |
| `topic-hub` | `主题名` | `AI Agent.md` |
| `ai-memory` | `稳定事实或偏好主题` | `内容语言偏好.md` |
| `audit-report` | `YYYY-MM-DD - 审计主题` | `2026-08-09 - 模板验证.md` |

## 模板命名

模板文件使用本阶段指定的英文名称，存放于 `90-Templates`。模板不是实际知识笔记，其 YAML 中必填实例值保持为空，复制后必须填写。

## 附件命名

归属明确时使用 `<主笔记名称>--<描述>.<扩展名>`；不得在附件名中放 Token、身份证号、手机号等敏感信息。临时附件只有在真实附件出现时才进入 Inbox 附件流程。

## 重命名约束

- 重命名前检查反向链接、外部引用和 Git 状态。
- 批量重命名必须展示映射表并取得确认。
- 重命名不得改变 `id`。
- 本规范不授权改造现有文件。
