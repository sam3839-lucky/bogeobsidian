# 核心观点

G.P.S. 系统把一套房产拆成三个理性指标：**G（Growth 增长潜力）**、**P（Product 产品力）**、**S（Self-Matching 自我匹配度）**。通过逐项量化打分再按权重加权，得到 0-100 的战略总分，用于判断一套房产是否值得投资、是否适合特定买家。属个人经验框架，置信度低，需结合官方数据与实地核验。

**总分判读**：80 分以上 = 优质资产（可重点考虑）；60-80 分 = 普通资产（优缺点明显，需权衡）；60 分以下 = 劣质资产（有硬伤，除非特殊理由否则拉黑）。

## 三因子总览

| 因子 | 全称 | 默认权重 | 本质 | 一句话 |
|---|---|---|---|---|
| G | Growth 增长潜力 | 35% | 房产的“命数” | 规划、产业、人 |
| P | Product 产品力 | 50%（核心） | 房产的“肉身” | 户型、楼龄、物业、车位 |
| S | Self-Matching 自我匹配度 | 15% | 与“你”的缘分 | 预算、通勤、核心需求 |

> P 权重最高：产品不行，一切都是空中楼阁。S 分是“临门一脚”：房子没有绝对好坏，只有适不适合你。

## 一、G 增长潜力评分标准

### G 维度结构（子项权重）

| 维度 | 权重 | 含义 |
|---|---|---|
| G1 宏观（城市能级） | 30% | 资产价值天花板 |
| G2 中观（板块势能） | 40% | 政府砸钱与否 |
| G3 微观（周边赋能） | 30% | 楼下配套与流动性 |

### G1 宏观 · 城市能级

| 分数 | 标准 |
|---|---|
| 10 | 全球一线城市（北上深） |
| 8-9 | 强一线 / 顶级二线（广杭） |
| 6-7 | 强二线核心城市（南京/成都/武汉等） |
| 4-5 | 普通省会 / 计划单列市 |
| 0-3 | 其他城市 |

### G2 中观 · 板块势能

| 分数 | 标准 |
|---|---|
| 10 | 市级宇宙中心（如前海/深圳湾） |
| 8-9 | 区级核心 / 热门新兴板块（如宝中/红山） |
| 6-7 | 成熟的次核心区 |
| 4-5 | 发展停滞的老城区 |
| 0-3 | 城市边缘或无规划区域 |

### G3 微观 · 周边赋能

**G3 得分 = G3.1×40% + G3.2×25% + G3.3×15% + G3.4×10% + G3.5×10%**

#### G3.1 轨道交通（40%）

| 分数 | 标准 |
|---|---|
| 10 | 枢纽级换乘站上盖 |
| 8-9 | 步行 5 分钟内达地铁口 |
| 6-7 | 步行 10 分钟内达地铁口（及格线） |
| 4-5 | 步行 15 分钟内 |
| 0-3 | 15 分钟以上 / 无地铁 |

#### G3.2 商业配套（25%）

| 分数 | 标准 |
|---|---|
| 10 | 顶级商圈环绕 |
| 8-9 | 步行 10 分钟内有大型商业体 |
| 6-7 | 步行 5 分钟内有大型超市 / 成熟社区商业 |
| 4-5 | 仅有底商便利店 |
| 0-3 | 匮乏 |

#### G3.3 教育氛围（15%）

| 分数 | 标准 |
|---|---|
| 10 | 名校环绕（中小幼） |
| 8-9 | 1 公里内教育链条完整 |
| 6-7 | 1 公里内有对应公立学校 |
| 4-5 | 资源单薄 |
| 0-3 | 教育荒漠 |

> 注意：这不是指学位，而是社区的“书香气”/人文环境。

#### G3.4 医疗健康（10%）

| 分数 | 标准 |
|---|---|
| 10 | 驾车 10 分钟内达三甲医院 |
| 8-9 | 驾车 15 分钟内达三甲 |
| 6-7 | 步行 10 分钟内有社康/门诊 |
| 4-5 | 保障不足 |
| 0-3 | 无 |

#### G3.5 文体休闲（10%）

| 分数 | 标准 |
|---|---|
| 10 | 步行 10 分钟达市/区级公园 + 公建 |
| 8-9 | 步行 10 分钟达大型公园 |
| 6-7 | 步行 10 分钟达社区公园 |
| 4-5 | 仅小区绿化 |
| 0-3 | 无 |

## 二、P 产品力评分标准（核心）

### P 维度结构（子项权重）

| 维度 | 权重 | 含义 |
|---|---|---|
| P1 核心骨架 | 60% | 户型/楼龄/楼层 |
| P2 外部配套 | 40% | 小区/物业/车位/梯户 |

### P1 核心骨架

#### P1.1 户型格局（30%）

| 分数 | 标准 |
|---|---|
| 10 | 神户型：动静分区 / 南北通透 / 全明格局 |
| 8-9 | 户型方正，主流好用 |
| 6-7 | 有小瑕疵（单面采光 / 暗卫） |
| 4-5 | 有明显缺陷（异形 / 过道长） |
| 0-3 | 反人类户型，严重影响居住 |

#### P1.2 楼龄房龄（20%）

| 分数 | 标准 |
|---|---|
| 10 | 5 年内次新 |
| 8-9 | 5-10 年 |
| 6-7 | 10-15 年（及格线） |
| 4-5 | 15-20 年 |
| 0-3 | 20 年以上老破大/小 |

#### P1.3 楼栋 / 楼层（10%）

| 分数 | 标准 |
|---|---|
| 10 | 楼王，视野景观俱佳 |
| 8-9 | 位置较好，无遮挡 |
| 6-7 | 普通位置，无明显硬伤 |
| 4-5 | 临街 / 低楼层 / 视野遮挡 |
| 0-3 | 靠垃圾站 / 变电站 / 腰线层等 |

### P2 外部配套

#### P2.1 小区品质（15%）

| 分数 | 标准 |
|---|---|
| 10 | 人车分流 / 大花园 / 会所 / 泳池 |
| 8-9 | 人车分流 / 优质园林 |
| 6-7 | 基本人车分流 / 有地面停车 |
| 4-5 | 无人车分流 / 绿化少 |
| 0-3 | 开放式 / 单体楼 |

#### P2.2 物业管理（10%）

| 分数 | 标准 |
|---|---|
| 10 | 顶级品牌物业（万科/金地/中海） |
| 8-9 | 口碑好的品牌物业 |
| 6-7 | 普通物业，服务到位 |
| 4-5 | 物业一般，反应慢 |
| 0-3 | 物业差 / 无物业 |

#### P2.3 车户比（10%）

| 分数 | 标准 |
|---|---|
| 10 | ≥ 1:1.2 |
| 8-9 | 1:1 - 1:1.2 |
| 6-7 | 1:0.8 - 1:1（及格线） |
| 4-5 | 1:0.5 - 1:0.8 |
| 0-3 | < 1:0.5 |

#### P2.4 梯户比（5%）

| 分数 | 标准 |
|---|---|
| 10 | 1 梯 1 户 / 2 梯 2 户 |
| 8-9 | 2 梯 3 户 |
| 6-7 | 2 梯 4 户（及格线） |
| 4-5 | 2 梯 5-6 户 |
| 0-3 | 3 梯 8 户以上 / 单梯多户 |

## 三、S 自我匹配度评分标准

| 子项 | 分数 | 标准 |
|---|---|---|
| S1 资金匹配·预算匹配度 | 10 | 轻松覆盖，月供 < 收入 30% |
| | 8-9 | 正好匹配，月供 < 收入 40% |
| | 6-7 | 略有压力，月供 < 收入 50%（警戒线） |
| | 4-5 | 压力较大，需动用消费贷 |
| | 0-3 | 严重超标，杠杆过高 |
| S2 生活匹配·通勤便利性 | 10 | 步行 / 单次 < 30 分钟 |
| | 8-9 | 单次 30-45 分钟 |
| | 6-7 | 单次 45-60 分钟（及格线） |
| | 4-5 | 单次 60-90 分钟 |
| | 0-3 | 单次 > 90 分钟 |
| S3 需求匹配·核心诉求满足度 | 10 | 完美命中所有核心需求 |
| | 8-9 | 命中第一诉求，兼顾其他 |
| | 6-7 | 命中第一诉求，其他有妥协 |
| | 4-5 | 未命中第一诉求 |
| | 0-3 | 与核心诉求背道而驰 |

## 四、战略权重表（按购房目的调整）

| 购房目的 | 权重 | G | P | S |
|---|---|---|---|---|
| 标准均衡型 | 默认 | 35% | 50% | 15% |
| 激进投资型 | 投资 | 50% | 35% | 15% |
| 纯粹自住型 | 自住 | 20% | 60% | 20% |
| 学区第一型 | 学位 | 30% | 30% | 40% |

## 五、核心诉求选项库（军团 · 反查用）

判断买家属于哪一“军团”，从而确定 S 分权重与选筹重点：

| 军团 | 核心诉求 | 英文标识 | 核心拷问 |
|---|---|---|---|
| 功能驱动（为“用”而买） | 学位 | Education | 学校变差后我还愿住吗？ |
| | 通勤 | Commute | 每天多 1 小时值得吗？ |
| | 居住 | Living Space | 真需要空间还是“看起来大”？ |
| 资产驱动（为“钱”而买） | 增值 | Appreciation | 三年不涨心态会崩吗？ |
| | 价格 | Price/Budget | 为省钱能忍受哪些硬伤？ |
| | 流动性 | Liquidity | 急用钱能一个月按市价卖掉吗？ |
| 体验驱动（为“爽”而买） | 圈层/环境 | Circle/Environment | 愿为好邻居付多少溢价？ |
| | 楼龄/品质 | Age/Quality | “新”值多少钱？ |
| | 景观/稀缺性 | View/Scarcity | 窗景对下家也有吸引力吗？ |

## 六、户型皮测评三板斧

户型 = 骨架 + 皮肉 + 灵魂，层层递进。

| 板斧 | 层面 | 看什么 | 关键判据 |
|---|---|---|---|
| 第一板斧 | 格局与动线（骨架） | 好不好用 | 动静分区 / 交通动线 / 户型方正 |
| 第二板斧 | 尺度与采光（皮肉） | 舒不舒服 | 采光通透性 / 空间尺度（开间） |
| 第三板斧 | 功能与增值（灵魂） | 值不值钱 | 功能完整性 / 市场偏好（流动性） |

**关键公式**：南北通透 + 三房两卫 + 户型方正 ≈ 绝大多数城市的“爆款公式” = 流动性之王。

## 七、决策引擎输入（情报包）

诊断前需收集三类信息：

1. **楼盘基础信息**：楼盘名称、城市与行政区、地址、开发商、楼龄、总户数、车位数、梯户比、物业公司/费、户型图、挂牌总价/单价、学区情况。
2. **用户画像**：家庭构成、职业与工作地、家庭年收入、购房预算、购房目的、需求优先级（如学位>交通>户型>价格）、核心诉求/痛点。
3. **作战指令**：作战模式（速览/标准/深度/对决/排雷）、竞品楼盘、战略权重、输出格式。

## 边界条件

- 属个人经验框架，评分标准与权重为定性归纳，非权威标准。
- 评分依赖用户输入与 AI 判断，需结合官方数据与实地核验。
- 本笔记仅记录方法论与评分标准，不构成具体楼盘购买建议。
