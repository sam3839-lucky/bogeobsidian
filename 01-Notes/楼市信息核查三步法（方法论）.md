# 核心观点

面对"一分钟说20个断言"这类密集信息轰炸的短视频，用三步法做事实核查：①这个数据我能查到吗？②这句话是事实还是推论？③说这话的人是什么立场？把断言分成"有数据支撑 / 半真半假 / 纯话术"三级。该方法论来自自媒体场景总结，置信度低。

## 论证

三步核查法：

- **第一步：数据能查到吗？** 能查到具体来源（如统计局、住建部官网）的断言，标记为"有数据支撑"；查不到的，打问号。一条连来源都不给的说法，不直接采信。
- **第二步：事实还是推论？** "北京二手房成交两万套"是事实；"成交涨了所以房价要涨"是推论。推论不等于事实，需要更多证据。
- **第三步：什么立场？** 卖房的希望你相信"要涨"，卖课的希望你相信"你不懂需要学"。立场决定他说什么、不说什么。

三级分类：

- **有数据支撑**：可交叉验证（如北京/上海二手房月度成交数据）。
- **半真半假**：话只说一半或偷换概念（如"房地产重回支柱产业"——支柱从未离开，"重回"是话术包装）。
- **纯话术**：无法验证、纯氛围营造（如"有钱人都在买"——无数据来源，是从众心理操控）。

## 边界条件

- 属个人经验总结，非权威方法论，置信度低。
- 三步法是"质疑框架"，不保证结论正确，最终以官方数据为准。
- 本笔记仅记录方法论，不构成对任何具体视频作者的贬损判断。
